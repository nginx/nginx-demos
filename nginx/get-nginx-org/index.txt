get.nginx.org (one-line installer for NGINX Open Source)

BEFORE YOU PASTE

  This script runs as root and changes your system. It adds the nginx.org
  package repository and its signing keys, then installs nginx. The
  repository and the keys stay on the system afterwards. The script
  prints how to remove them when it's done.

  Piping a download into a shell runs it unread. Read the script before
  you run it: see "Review first" below.

  The script is provided "as is", without warranty of any kind. You use
  it at your own risk. See LICENSE at the end of this page.

NGINX OPEN SOURCE

  https://get.nginx.org/nginx installs NGINX Open Source from the
  nginx.org package repositories. This page, https://get.nginx.org/,
  isn't the installer: don't pipe it into a shell.

  Install the mainline branch:

  curl -q --proto '=https' --tlsv1.2 -fsSL https://get.nginx.org/nginx | sh

  Install the stable branch:

  curl -q --proto '=https' --tlsv1.2 -fsSL https://get.nginx.org/nginx | sh -s -- --stable

  Install with dynamic modules:

  curl -q --proto '=https' --tlsv1.2 -fsSL https://get.nginx.org/nginx | sh -s -- --module njs --module otel

  Show the plan and the commands, change nothing:

  curl -q --proto '=https' --tlsv1.2 -fsSL https://get.nginx.org/nginx | sh -s -- --dry-run

  Review first, then run the copy you read:

  curl -q --proto '=https' --tlsv1.2 -fsSL https://get.nginx.org/nginx -o install-nginx.sh
  less install-nginx.sh
  sh install-nginx.sh --dry-run
  sh install-nginx.sh

  Dockerfile or CI job: don't pipe from the network on every build. Keep
  a copy you have read, check its SHA-256, and skip the pause:

  echo "HASH  install-nginx.sh" | sha256sum -c - && sh install-nginx.sh --yes

  Replace HASH with the first word printed by: sha256sum install-nginx.sh

  Options, after "sh -s --" or after the file name:

    --mainline      mainline branch (the default)
    --stable        stable branch
    --module NAME   also install the nginx-module-NAME package
                    NAME: acme geoip image-filter njs otel perl xslt
                    repeat the option for more modules
                    on the stable branch, RHEL, Amazon Linux, and
                    SLES 16 have no geoip
    --unattended-upgrades
                    Debian and Ubuntu: let unattended-upgrades install
                    nginx updates from nginx.org (off by default)
    -n, --dry-run   show the plan and the commands, change nothing on the
                    system (it still downloads and checks the signing key)
    -y, --yes       skip the 10-second pause
    -h, --help      all options, supported systems, and how to undo

  Before and after you run it:

    - Run it as root, or as a user who can use sudo or doas.
      Pipe into sh, not into sudo sh.
    - Keep -q first and --proto '=https'. -q ignores ~/.curlrc (where an
      "insecure" line disables TLS checks) and --proto '=https' refuses
      plain HTTP.
    - The script shows its plan, then waits 10 seconds before it changes
      anything. Press Ctrl+C to cancel.
    - An nginx that is already installed is replaced or upgraded.
      Back up /etc/nginx first. If the distribution's nginx packages
      can't be replaced in one install, as on RHEL 9 and 10 and Amazon
      Linux 2023, or the distribution's own module packages would be
      left behind, the script stops before it changes anything and
      prints the command that removes them.
    - If the install fails, the script undoes its changes to the
      package sources.
    - Security-only updates (dnf upgrade --security, zypper patch)
      skip nginx.org packages. Update nginx with a full upgrade. On
      Debian and Ubuntu, unattended-upgrades skips them too, unless
      you run the script with --unattended-upgrades.
    - Running it again upgrades nginx on the chosen branch. It never
      downgrades on its own: moving from mainline to stable stops with
      the command to run.
    - When it is done, the script prints how to start nginx, and how
      to remove the repository and keys.

  Supported systems, on x86_64 and aarch64:

    RHEL and derivatives   8, 9, 10
    Debian                 12, 13
    Ubuntu                 22.04, 24.04, 26.04
    SLES                   15 SP7 or later (x86_64 only), 16
    openSUSE Leap          16
    Alpine                 3.22, 3.23, 3.24
    Amazon Linux           2023

  Manual installation steps: https://nginx.org/en/linux_packages.html
